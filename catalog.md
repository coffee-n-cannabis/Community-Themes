## Full raw-URL pattern

Append any theme's CSS path to:

```
https://git.coffee-n-cannabis.com/CnC/Community-Themes/raw/branch/main/
```

Example for Matrix:

```
https://git.coffee-n-cannabis.com/CnC/Community-Themes/raw/branch/main/themes/matrix/matrix.css
```

Paste that URL into your UNIT3D **Settings → General → Style → Standalone CSS Stylesheet** field. Save. Done.
