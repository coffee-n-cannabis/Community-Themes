## Checklist (for new themes)

- [ ] My CSS lives in `themes/<theme-name>/<theme-name>.css` (kebab-case)
- [ ] I've filled in `themes/<theme-name>/README.md` (description, author, screenshot, license if not MIT)
- [ ] I've added `themes/<theme-name>/preview.png` (~1200px wide)
- [ ] I've added a row for my theme in `catalog.md`
- [ ] My theme targets current UNIT3D BEM markup (`panelV2`, `form__group`, `nav-tabV2`, etc.) — not removed/old markup
- [ ] My palette is in CSS custom properties near the top (so others can remix easily)
- [ ] No third-party JS, no `@import` from CDNs that could disappear, no telemetry
- [ ] If I forked / adapted someone else's work, I've credited them in the theme's README

## Checklist (for fixes to existing themes)

- [ ] I've left the theme's palette custom-property names alone (so remixers' overrides don't break)
- [ ] I've described what visually changed in the PR body
- [ ] If it's a layout fix, I've noted the page(s) affected (home, torrents, chat, settings, etc.)
